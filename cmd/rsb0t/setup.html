rsb0t-go setup

Choose your server, add your accounts, choose what each one does, then press Start. Passwords stay on this computer, in the rsb0t-data folder, and are never shown again.

1. Your game server

The address of the server's website or of the page where you play, like https://example-server.com or w1.example-server.com. It must be a RuneScape 2 revision 289 server (for example one built on LostCity); other revisions will not work.
Login key (only if the check asks for it)
The server keeps a "login key": two numbers your password is locked with before it is sent. rsb0t normally reads them from the server by itself. Fill these boxes only when the check says it could not, with the numbers the server's staff give you (or that the check tells you where to copy from). Leave them empty otherwise.
A key typed here is kept and used as it is. If the server later changes its key (some do when they restart), every login is refused with "response 6" until you paste the new one.
Game connection address (only if the server's staff give you one)
Most servers run the game on the same address as their website, and rsb0t finds it. If the check says the game connection is not where it looked, ask the server's staff for the game's address (it starts with wss:// or ws://) and type it here.

    2. Add an account

    A login name is up to 12 letters, digits, spaces or underscores. Add only accounts that are yours: on some servers a login with a new name creates that account. Start with no script to check the login works; you can change the script and its settings after adding.
    Scripts marked "needs map data" walk around the world and will not start without a collision pack (the packPath setting), which this download does not include. Without it, choose "(none: just log in)" or a script without the mark.
